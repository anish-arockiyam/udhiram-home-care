# UDHIRAM HOME CARE NURSING — Angular 20

Premium one-page home-care nursing website built with Angular 20 standalone components.

## Run locally

```bash
npm install
npm start
```

Open the local URL shown by Angular CLI.

## Production build

```bash
npm run build
```

## Main structure

- `src/app/components/header` — sticky responsive navigation
- `src/app/components/section-heading` — reusable section heading
- `src/app/shared/icon.component.ts` — dependency-free inline icon set
- `src/app/pages/home` — complete landing page and enquiry form
- `src/styles.scss` — global design tokens, typography and accessibility
