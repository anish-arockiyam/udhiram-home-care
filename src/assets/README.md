# Replaceable assets

The initial design uses remote Unsplash images so the Angular project is immediately visual.

For production, replace the image URLs in `src/app/pages/home/home.component.html` with your own licensed/client-approved photography and store those files under `src/assets/images/`.

Suggested filenames:
- hero-caregiver.webp
- care-at-home.webp
- care-banner.webp
- og-cover.webp
